## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
AeroForm AI 🏃‍♂️📊
AI-Powered Athletic Biomechanics & Performance Analysis Platform

AeroForm AI is a professional-grade sports biomechanics platform designed to bring elite-level athletic analysis to everyday training environments. By leveraging advanced AI vision-language processing, the platform transforms standard athlete photos or motion frame sequences into a detailed technical performance dashboard.

Built for athletes, coaches, trainers, and sports analysts, AeroForm AI delivers intelligent motion analysis, biomechanical insights, and Olympic-level benchmarking without requiring expensive lab equipment.

📦 Installation

Clone the repository:

git clone https://github.com/MohithKumar223/AeroForm-AI.git

Navigate into the project folder:

cd AeroForm-AI

Install dependencies:

npm install

Run the development server:

npm run dev

Build for production:

npm run build
🔑 Environment Variables

Create a .env file in the root directory and add:

VITE_GEMINI_API_KEY=your_api_key_here
